# Tesseraft documentation

Choose the smallest document that owns the question:

- [`guides/`](guides/) — task-oriented setup and workflow guides.
- [`reference/`](reference/) — stable CLI, API, package, schema, and runtime contracts.
- [`architecture/`](architecture/) — accepted ownership and boundary decisions.
- [`design/`](design/) — active or accepted product designs.
- [`testing/`](testing/) — test graph, browser checks, and manual judgment procedures.
- [`operations/`](operations/) — deployment, recovery, and operator procedures.
- [`generated/`](generated/) — capability evidence generated from `STATUS.edn`.
- [`archive/`](archive/) — superseded plans and historical implementation prompts.

The active outcome-level plan is [`ROADMAP.md`](../ROADMAP.md). Every architecture and design document declares status, decision date, and supersession metadata.
