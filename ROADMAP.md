# Tesseraft roadmap

Status: Active
Updated: 2026-08-10

The active roadmap tracks outcomes rather than implementation diaries.

1. Complete stable cross-language wire schemas and generated TypeScript types.
2. Finish extracting the runtime state machine, linter rule families, and package transaction helpers behind their public façades.
3. Expand contract-level recovery coverage across supported operating systems.
4. Define a trust and lifecycle model before allowing executable third-party providers.

Completed plans and historical implementation prompts are retained under `docs/archive/` when they remain useful evidence.
